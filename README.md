# Dilawar Ali — Portfolio & AI Engineering Showcase

A modern, high-performance developer portfolio built with **Next.js 15 (App Router)**, **React 19**, **Node.js**, and **Tailwind CSS v4**.

Designed specifically for **Dilawar Ali** — Data Scientist & AI Automation Engineer based in Multan, Pakistan.

---

## ⚡ Tech Stack & Features

- **Framework:** Next.js 15 (App Router)
- **Runtime:** Node.js (v18+)
- **Styling:** Tailwind CSS v4 + Custom Design System
- **Icons:** Lucide React
- **Interactive Demos:**
  - Dynamic AI Automation Pipeline Visualizer (n8n / LLM / Webhooks simulation)
  - Interactive Project Filtering (Automation, Machine Learning, Computer Vision, Backend)
  - Working Contact Form backed by a serverless Node.js API route (`/api/contact`)
- **SEO & Social Sharing:**
  - Automated OpenGraph & Twitter preview cards
  - Person & Portfolio JSON-LD Schema markup for Google Rich Results
  - Native Google Fonts with zero layout shift (`Space Grotesk` & `DM Sans`)

## 🚀 Getting Started Locally

Ensure you have [Node.js](https://nodejs.org/) installed (v18.18 or newer).

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploying to Vercel (100% Free Tier)

This project is optimized for deployment on **Vercel**:

1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of Next.js portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Go to [Vercel](https://vercel.com/) and sign in with GitHub.
3. Click **"Add New Project"** and select your repository.
4. Leave the default settings (Vercel automatically detects Next.js) and click **"Deploy"**.
5. Your portfolio is live with a free `.vercel.app` domain and free SSL!
